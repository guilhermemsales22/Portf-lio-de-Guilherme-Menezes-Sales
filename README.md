# Portfólio — Guilherme Menezes Sales

Site estático de uma página, responsivo, feito com HTML, CSS e JavaScript puros.

## Como abrir
Abra `index.html` no navegador. Não precisa instalar dependências.

## Como publicar no Vercel
1. Envie `index.html` **e** `foto-guilherme.png` para um repositório GitHub, mantendo os dois na mesma pasta.
2. Crie um projeto no Vercel e importe o repositório.
3. Selecione **Other** ou **sem framework**, sem comando de build. O arquivo `index.html` deve ficar na raiz.
4. Clique em **Deploy**.

## Antes de enviar para o RH
- Confirme se os links de GitHub e LinkedIn abrem corretamente.
- Confirme se os projetos públicos estão atualizados e têm README.
- Substitua ou acrescente links de demonstração apenas quando existirem.
- Revise se a descrição e o estado de cada projeto correspondem à versão publicada.
- Caso deseje, adicione link para um currículo PDF publicado na mesma pasta.
